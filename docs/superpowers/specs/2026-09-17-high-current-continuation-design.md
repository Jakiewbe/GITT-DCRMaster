# 高电流截断后延续脉冲设计说明

## 目标

对于比电流大于或等于 500 mA·g⁻¹、且在声明的 1.5 V 截止电压附近仍继续循环的 NDAX 数据，识别后续结构完整的脉冲，并将符合规则的延续脉冲作为可计算结果进入主图和正式导出。比电流低于 500 mA·g⁻¹的数据继续使用原有首次截止后停止保留规则。

## 不改变的内容

- 不把实验协议的 1.5 V 截止电压改成 1.0 V。
- 不改变 GITT Endpoint、ΔEt、ΔEs、WH、DCR、CFx_10s 或回归公式。
- 不改变 loaded t=0 选择、缺失 t=0 的不可计算规则、几何参数、活性物质质量处理或 pulse duration 定义。
- 不对 τ–电压回归补点，也不放宽现有最小点数和拟合质量要求。
- 低于 500 mA·g⁻¹的数据不启用本规则。

## 规则边界

### 启用条件

使用项目已有的等效比电流字段，满足 `equivalentSpecificCurrentMahPerG >= 500` 时启用高电流延续模式。不得用文件名、绝对通道电流或新建电流阈值替代该字段。

### 序列分组

事件分为两组：

1. `main_protocol_sequence`：首次声明截止电压事件及其之前的事件，保持原有主序列语义。
2. `high_current_post_cutoff_continuation`：首次截止事件之后的事件，仅在高电流模式下按延续规则重新审核。

低电流模式仍只返回原有保留序列，首次截止后的事件不进入结果序列。

### 延续事件合格条件

首次截止后的事件只有同时满足以下条件，才成为可计算的高电流延续事件：

- 原始 CanonicalRow 中仍能识别出脉冲和后续 Rest 的物理顺序；
- 脉冲和 Rest 数据均存在，且没有文件末尾截断、缺失 Rest 或未完成 Rest；
- Endpoint 所需的 loaded t=0 合格；
- 事件的现有数值计算状态可计算；
- 事件不是仅由文件尾部残留或无法解释的分段产生。

如果事件不满足条件，保留其排除原因，但不得进入主图、主趋势或正式可计算导出。

### 主图和导出

- 符合条件的延续事件进入主图和主结果表，并保留明确的 `post_cutoff_continuation` 来源标记。
- 主图中的延续点与普通主序列点使用同一坐标和计算单位，但图例/表格必须能识别其来源。
- 不合格事件不得因为“显示全部文件”而进入正式主趋势。
- 导出至少保留事件来源、比电流、截止前后序列分类、协议状态、数值计算状态和 QC 状态，确保用户可以区分标准协议点与延续点。

## 数据流

1. NDAX 解析得到程序声明的 Stop_Volt、脉冲/Rest CanonicalRow 和已有电流信息。
2. 现有事件分段与科学计算先按原规则完成。
3. 产品层根据等效比电流判断是否启用延续模式。
4. 高电流模式下，对首次截止后的事件执行完整结构和计算状态审核。
5. 合格事件加入主结果序列；不合格事件仅保留排除状态。
6. UI、主图模型和导出使用同一个审核后的结果序列，禁止各层各自重新判断。

## 测试验收标准

- 比电流为 499.9 mA·g⁻¹时，首次截止后的事件仍不进入主序列。
- 比电流为 500 mA·g⁻¹时，结构完整且 Endpoint 可计算的延续事件进入主序列、主图和导出。
- 高电流延续事件缺失完整 Rest 或 loaded t=0 时，不进入主图和正式导出。
- 已有 1.5 V 标准数据的 Endpoint、ΔEt、ΔEs、medianVoltage、pulse duration、DCR 和 CFx_10s 数值保持不变。
- 不改变首次截止事件之前的数据顺序和原有 QC 状态。
- UI 和导出不会把排除事件误显示为主结果。

## 采用的方案

采用“主序列 + 高电流延续序列”的方案。延续脉冲只有通过现有科学计算和完整结构审核后，才进入主图与正式导出；它们不会被伪装成未发生截止的标准协议事件。
