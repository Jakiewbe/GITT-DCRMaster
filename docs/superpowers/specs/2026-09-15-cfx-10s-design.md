# CFx 10 s GITT preset design

## Goal

在不改变 Endpoint WH、median voltage、pulse duration、DCR 或现有高分辨率选点能力的前提下，为约 10 s 采样的 CFx GITT 数据建立正式的 `CFx_10s` 二级 slope 诊断流程。

## Frozen scientific decisions

- `metricValueCm2PerS` 继续是 `D_endpoint`，不被 slope 结果替换。
- `CFx_10s` 选点范围为 `0 < t <= 64 s`，拟合得到 `E = a + k√t`。
- slope-based D 使用完整实际恒流 pulse 时长 `τ`，不使用 64 s 或回归窗口时长。
- `legacy_first_5` 保留为 window robustness reference，规则不变。
- 原 `cfx_4_25s` 和 `cfx_1_64s` 保留为 generic/high-resolution research presets，不进入 CFx 10 s 默认流程。
- `medianVoltageV` 继续从当前 NDAX pulse 数据读取，算法不变。
- 不实现 adaptive window、自动最佳窗口、自动删除初始 pulse、平滑或插值。

## Data model

现有 fixed-time selector 继续负责时间边界、排序、唯一时间点和实际窗口范围。新增边界语义，使 `CFx_10s` 能表达开区间下界 `0 < t`，而不复制另一套选点算法。

`GittRegressionWindowResultV1` 增加：

- `samplingCoverage`: `full` / `partial` / `infeasible` / `not_applicable`；只对 `CFx_10s` 使用 6/5/<5 点规则。
- `linearityClass`: `strong_linearity` / `acceptable_review` / `early_response_nonlinear` / `unavailable`；仅表达 R² 分层，不直接删除结果。

`GittResultV1` 增加仅用于诊断的：

- `windowStabilityDecades = abs(log10(D_legacy_5pt) - log10(D_slope_10s))`
- `methodDivergenceDecades = log10(D_slope_10s) - log10(D_endpoint)`
- `absMethodDivergenceDecades`
- `endpointStartTemporalResolutionS = firstPositivePulseTimeS`
- `initialObservedDropV = preRestEndPotentialV - firstPositiveTimePulseVoltageV`

这些字段任一输入不可用时返回 `null`，不参与 Endpoint D 计算。

## Default and research presets

默认 CFx workflow 只返回：

1. `legacy_first_5`：稳健性参考；
2. `cfx_10s`：正式二级 slope 诊断，固定范围 `0 < t <= 64 s`。

底层继续导出显式的 `HIGH_RESOLUTION`/generic preset 常量，包含 `cfx_4_25s` 和 `cfx_1_64s`。两者与 `cfx_10s` 共用 fixed-time selector，因此相同数据不会因为 selector 重复实现而产生不同数值。

## UI, plot and export

- 主卡片继续显示 Endpoint WH。
- 增加 CFx 10 s slope D、实际拟合范围、斜率、截距、R²、RMSE、点数、coverage、linearity、window stability、method divergence 和 early observed drop。
- E–√t 诊断默认标识 CFx 10 s 选点；Legacy 仍可在结果明细中审查。
- D–Voltage 主图继续 `medianVoltageV vs D_endpoint`；CFx 10 s 作为独立可选 series，不归一化。
- GITT Summary、GITT Regression Windows、GITT D-Voltage 和 Manifest 增加对应字段与 `CFx_10s` 语义。

Manifest 固定记录：

```text
analysisPreset = CFx_10s
samplingAssumption = approximately 10 s pulse recording
regressionRequestedWindow = 0 < t <= 64 s
primaryMetric = endpoint_WH
secondaryMetric = slope_WH_CFx_10s
```

## Compatibility and validation

- Endpoint 的数值用原始测试 fixture 做数值容差回归。
- median voltage、ΔEt、ΔEs、pulse duration 做显式不变性断言。
- DCR 通过现有 DCR 测试和独立结果哈希/数值断言保持不变。
- 新增 10 s、60.1 s、5 点、<5 点、Legacy 兼容、稳定性公式和高分辨率 preset 测试。
- 最后重新分析当前 3 个 CFx NDAX，分别报告 CFx 10 s coverage、R² 分层、window stability、Endpoint–slope divergence，并验证修改前后冻结量。
