# CFx 10 s GITT preset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 Endpoint WH 为主值的前提下，为约 10 s 采样 CFx GITT 建立可审计的 `CFx_10s` slope 诊断、UI、导出和真实数据复核。

**Architecture:** 复用现有 `evaluateRegressionWindow` fixed-time 选点器，通过显式边界语义实现 `0 < t <= 64 s`；只为 `cfx_10s` 增加采样完整性和语义诊断。Endpoint、median voltage、pulse duration 和 DCR 走原路径不变，新的比较量作为 GITT 结果诊断字段和导出列传播到 UI。

**Tech Stack:** TypeScript、React、Vitest、现有 NDAX adapter、现有 XLSX/CSV export pipeline。

## Global Constraints

- `D_endpoint` 继续是 `metricValueCm2PerS`，不得替换。
- `CFx_10s` regression window 为 `0 < t <= 64 s`。
- slope D 使用完整实际恒流 pulse duration `τ`。
- `legacy_first_5` 保持现有选点规则和结果兼容。
- `cfx_4_25s` 和 `cfx_1_64s` 保留为显式 generic/high-resolution preset，不进入默认 CFx 10 s workflow。
- `initialObservedDropV = preRestEndPotentialV - firstPositiveTimePulseVoltageV`，不得命名为 IR drop，不进入 D 计算。
- 禁止 adaptive window、自动最佳窗口、自动删除 pulse、平滑原始数据和插值造点。
- DCR 代码和结果不得修改。
