# PulseLab 0.1.0-beta.3

- 项目页优先展示文件列表，可全选、多选移除、单文件移除或清空；使用软件内确认框，只影响当前项目，不删除磁盘原始文件。移除时同步清理逐文件参数、缓存和详情选择。
- 新项目预填 12 mm 极片直径，统一确认 CFx 体系；不再按 CFx / FGS 文件名分别选择计算口径。旧项目保留原参数，非 CFx 不自动套用 CFx GITT 模型，DCR 独立工作。
- 支持明确 mg、g、µg 及中文单位的质量文字；文件中质量缺失时可使用唯一一致的明确单位来源；有冲突时继续要求确认，不从无单位编号猜质量。
- 每个文件分配独立颜色并随项目保存；曲线按文件身份分组，避免同名或缩略名系列被合并。
- D–电压纵轴按 log10 位置映射，主刻度以整十次幂显示，支持反向展示；D 数值、比较资格和导出数据不做对数替换。
- 大文件分析按顺序执行，只保留当前文件和参数版本的分析缓存；科学哈希分块计算保持原字节口径；项目改为分块 `.pulselab` 保存和后台校验恢复，仍可读取旧 JSON。
- XLSX 工作表分块生成，桌面下载逐块读取 Blob，不再同时构造完整 XML 字符串和完整下载字节副本。

## 计算边界

未修改 GITT / DCR 公式、loaded t=0 定义、静置估计窗口、ΔEt / ΔEs、中值电压定义或 QC 数值判据。更改用户确认的质量、极片直径、材料参数时仍会重新计算，不将不同输入伪装为同一个结果。

软件仍需在内存中保留当前项目的 Canonical 数据；分块保存和顺序分析不代表无限容量。`.pulselab` 项目包含规范化测量数据，请按原始实验资料妥善保管，不提交公共仓库。

## 开发验证

`npm run check` 执行可移植回归测试与构建。历史私有数据验收通过 `npm run test:qualification` 单独运行，需要完整的本机实验文件、收据和独立工步表；缺失证据或哈希变化不修改为通过，不将该类审计计入软件单元测试通过数量。
